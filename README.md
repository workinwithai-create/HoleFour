# HoleFour

Four-bar stop-time desk for bedroom producers and AI-music finishers.

Suno and loop DAWs keep the pattern running through the turnaround. Session players write a stop: a band hit, a hole, an answer, then the next section on 1.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, and an acoustic kit. No oscillators. Audio never leaves the tab.

## Distinct from yesterday and the line

Yesterday's ship was PedalEight (a held pedal under moving chords). HoleFour is the opposite motion: the band stops.

| Tool | Job |
| --- | --- |
| PedalEight | Hold a pedal so the section has gravity |
| PickBar | Pickup into bar 1 |
| MuteEight | Subtract lanes for eight bars |
| TagFour | Last-line tag after the money chorus |
| PreEight | Musical climb before the hook |
| AfterHook | Eight bars after the hook |
| EndEight | Last eight of the record |
| LastHook | Rewrite the last chorus |
| LiftTwo | Short production lift |
| **HoleFour** | Four bars of written stop-time on the turnaround |

## Loop

1. Set BPM, key, and four chords. Those persist and drive playback and export.
2. Hear A (the print that never leaves) against B (the stop). Loudness is matched.
3. Pick a recipe. Change it while playing. It lands on the next step.
4. Export a loop WAV (tail folded onto sample 0) and a MIDI file, one chair per track.
